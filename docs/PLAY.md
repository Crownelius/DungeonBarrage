# Playing Dungeon Barrage

Dungeon Barrage is a turn-based artillery duel. Choose a fighter, read the wind, and decide on
every turn whether to defeat the rival through direct damage or by destroying their footing and
knocking them out of the dungeon. Both tactics remain available throughout the match.

## Start a local duel

1. Press **Enter** on the title screen.
2. Choose an arena with **Left/Right**, then press **Enter**.
3. Choose a fighter with the arrow keys or mouse, then press **Enter** (or select the continue
   button).

Press **Escape** to return to the previous screen. Press **S**, or select **Settings + Access**, to
open player settings from the title screen.

## Match controls

| Action | Control |
|---|---|
| Move | **A / D** |
| Jump | **W** or **Space** |
| Main attack — direct damage | **1** or select its action card |
| Secondary attack — terrain/ring-out pressure | **2** or select its action card |
| Charged SS bonus | **3** or select its action card |
| Aim and fire | Hold **left mouse**, drag, then release |
| Cancel aim | **right mouse** or **Escape** |
| Pass | **P** |
| Pan camera | **Arrow keys** |
| Refocus camera | **F** or **Home** |

The aiming preview is intentionally one dotted line. Gold means the authority preview intersects a
visible target body. Red means it does not; that can still be the correct shot when breaking terrain
or setting up a ring-out.

Main and secondary attacks have unlimited uses. The secondary is the weaker damage option, but it
preserves the ability to pressure terrain and displacement without consuming ammunition. The SS is
a charged bonus, not a replacement for either normal tactic.

## Results

- Press **Enter** or **R** to rematch with the same setup.
- Press **Escape** to return to the title screen.

## Settings and accessibility

On the Settings + Access screen:

- Use **Up/Down** to select a setting.
- Use **Left/Right** or **Enter** to change it.
- Press **R** to restore defaults.
- Press **Escape** to save and return to the title screen.

Settings save immediately. Reduce Motion is applied to the retro cabinet backdrop. Audio playback
and global application of high-contrast/text-scale settings are still integration work; the current
screen persists those preferences without claiming that unfinished behavior is active.
